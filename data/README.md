# data/

Put the sample input files your program reads in this folder, and
commit them.

- Use the files here in your live demo and in the test cases of your
  technical report.
- Keep every file small (well under 1 MB).
- Describe each file's format in the main README.md, Section 4.
- Your program should open these files with paths relative to the
  repository root, for example `data/sample.txt`, and run from the
  repository root (`./project`).
